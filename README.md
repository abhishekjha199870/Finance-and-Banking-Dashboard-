# Finance-and-Banking-Dashboard

A Power BI and SQL analytics project focused on customer behavior, transaction trends, risk analysis, and loan performance.

## Overview
This dashboard helps analyze:
- customer trends
- transaction patterns
- risk exposure
- loan performance
- regional and account type behavior

## Business Objective
To explore customer trends, transaction patterns, risk insights and loan performance.

## KPI Highlights
- Total Customers
- Total Transaction Amount
- Average Transaction Amount
- Total Balance
- Loan Approval Rate
- Average Credit Score
- High Risk Customers

## Tools Used
- Power BI
- SQL
- DAX
- Power Query

## Key Features
- Customer insights and segmentation
- Risk analysis
- Loan performance tracking
- Transaction trend analysis
- Regional performance comparison
- Executive reporting
